# Kraljica šah

Višestranična web stranica šahovskog kluba Kraljica šah iz Koprivnice.
Klub nudi tečajeve za početnike, pripremu za natjecanja, slobodnu igru i blitz šah, za djecu, mlade i odrasle.
Stranica je oblikovana isključivo Tailwind CSS utility klasama uključenima putem CDN-a, bez vlastite CSS datoteke,
i prilagođena je mobitelima, tabletima i računalima.

## Stranice

- `index.html` – naslovnica s uvodom, pregledom tečajeva i cijena
- `usluge.html` – detaljan opis tečajeva, raspored termina i postupak upisa
- `kontakt.html` – adresa, radno vrijeme i obrazac za upis na tečaj
